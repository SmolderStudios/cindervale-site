Read me first

This is the running list of 3D models for SLOTROOM — a PS1/PSX-style horror slot-machine game (walk around a grimy room, play a cursed slot machine, survive the nights). Each card is one model.

How to use a card: copy its prompt → paste into ChatGPT (or any image AI) to make one clear reference image → send that image to Troper, who turns it into a 3D model (Tripo image-to-3D) and drops the .glb in the Drive folder under the filename shown. Anything that can't be shown in a picture (blank screen, "rig it", removable, size) is in the card's notes — pass that along as text.

Click the status button on a card to cycle it Not started → Working on it → Delivered. Status is shared — everyone looking at this page sees the same thing, and it updates within a few seconds (the badge up top shows when you're connected). Finished .glb files still go in the shared Drive folder.

Start with the P0 cards — the characters and the slot machine are where real models help most. P1 charms are small collectible props. P2 are environment dressing — nice-to-have, the game already has placeholder versions.

How this works — Troper only does 4 things

These are made in Tripo, so no Blender skill needed. For each card:

  • 1 · Generate it in Tripo — paste the card's prompt into text-to-3D, or (usually better) drop the card's reference image into Tripo's image-to-3D.
  • 2 · Export as .glb — that's the format the game loads. (GLB, not FBX or OBJ.)
  • 3 · Name the file exactly what the card says, lowercase — e.g. prisoner.glb.
  • 4 · Drop it in the Drive folder → shared Google Drive folder ↗.

Don't worry about any of this — the game fixes it automatically on import

Troper does not need to touch these in Blender. Claude handles them in code when the model goes in:

  • Size, position & facing — auto-scaled to the right size, centered, and turned to face the room. Whatever scale/rotation Tripo spits out is fine.
  • The retro PS1 look — flat shading, crunchy low-res textures and the wobble are all added on the way in. Tripo's smooth, shiny, modern output is expected; it gets crushed into the style automatically.
  • Shiny / PBR / normal maps — ignored by the game, so it doesn't matter if Tripo bakes them in.
  • Animation IS wanted for the characters now — anything with a 🎬 needs animation tag should come rigged with animation clips (Tripo's rig + animate). A bare rig with no clip is still frozen, so include at least an idle (and a walk on the prisoner). The game auto-plays them. Everything without the tag stays static — Claude animates those in code (doors, lever, etc.).

⚠ Everything delivered so far is STATIC — the animated characters need redoing

Checked directly inside the files: the collector.glb and the watcher.glb both contain 0 animation clips and 0 skeletons. They're plain frozen meshes. That's not a game bug — there is genuinely nothing in the file to play, which is why the collector stands in a T-pose instead of sitting or walking. The rig + animate step in Tripo has to actually be run before export; a normal Tripo export skips it.

  • Clips the dealer needs, named exactly (lowercase): sit_idle, stand_up, walk, idle. He waits sat in a chair down a corridor, stands when the night's debt comes due, walks to the door, and sells you charms there. If only one clip is possible, make it walk.
  • NO root motion — this one silently ruins it. Walk on the spot; the game drives where he actually moves. If the walk clip travels forward, he'll slide away from where the code puts him.
  • Keep the rig humanoid and simple. If Tripo can't rig it, a free Mixamo auto-rig works: upload the static .glb/.fbx, let it rig, then grab Idle, Walking, Sitting and Stand Up — download with skin, and tick in-place on the walk.
  • One character, not three. The door currently spawns a floating head, a pair of eyes and a walking figure. That's collapsing down to just the dealer walking up — so the collector is the priority; the watcher's animation can wait.

The only two things that actually matter for the model

  • Make it the right thing — match the card's description. If Tripo offers a lower-poly / cleaner option, take it; if not, whatever it gives is fine.
  • Anything the game draws on has to be left blank — that's the slot cabinet's reel window and lit belly panel, plus the two wall boards (symbol_board, pattern_board). Those are empty frames, not signs: the chart on them is repainted live every time a charm is fitted, so any writing baked into the middle just shows through underneath it. Their cards carry the exact panel size and how deep to recess it — those numbers aren't optional, the game paints onto a fixed rectangle.

Reference images will fill in on the cards as they're added, so image-to-3D is the smoothest path.
